- Update planning policy -> `.agents/planning/agent.md`

- Update speckit guidance behavior -> `.agents/speckit-best-practices/agent.md`
- Update quota resume behavior -> `.agents/quota-monitor/agent.md`, `.agents/scheduler/agent.md`, `.agents/continuity-coordinator/agent.md`
