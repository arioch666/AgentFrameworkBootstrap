# Plans Index

This directory is an index for technical plans generated from specs.

Authoritative plan artifacts are stored here:

- `.specify/specs/<FeatureId>/plan.md`

## Adding a new plan

For an initiative with `FeatureId`, ensure:

1. `spec.md` exists under `.specify/specs/<FeatureId>/`
2. Your Spec Kit-capable agent runs `/speckit-plan` to generate `plan.md`
