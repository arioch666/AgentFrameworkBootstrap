# Tasks Index

This directory is an index for actionable implementation task breakdowns generated from plans.

Authoritative tasks artifacts are stored here:

- `.specify/specs/<FeatureId>/tasks.md`

## Adding new tasks

For an initiative with `FeatureId`:

1. Ensure `plan.md` exists under `.specify/specs/<FeatureId>/`
2. Ask your Spec Kit-capable agent to run `/speckit-tasks`
3. Execute `/speckit-implement` after task generation completes
