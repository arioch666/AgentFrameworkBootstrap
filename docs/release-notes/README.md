# Release notes (copy/paste helpers)

These files exist to make GitHub Releases easy to write even when release automation is not configured.

Workflow:

1. Create the git tag on the correct branch (`framework-v*` on `develop`, `pack-*-v*` on pack branches).
2. Push the tag: `git push origin <tagname>`
3. Create a GitHub Release from the tag.
4. Copy/paste the **GitHub Release** section from the matching file below.
