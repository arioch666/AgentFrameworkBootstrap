# Open Source Readiness

## Scope

This document prepares the framework for a future open-source release. It does not publish the project yet.

## Future Release-Readiness Items

- choose a license and place it at repository root as `LICENSE`
- document contribution expectations
- document issue and pull request expectations
- document project scope, goals, and non-goals
- document support expectations and disclaimers

## Recommended Future Files

- `LICENSE`
- `CONTRIBUTING.md`
- `.github/ISSUE_TEMPLATE/`
- `.github/pull_request_template.md` (if not already present or if it needs open-source wording)
- `CODE_OF_CONDUCT.md` (optional but recommended)
- `SECURITY.md` (recommended if public)

## Decision Notes

Before release, decide:

- what license to use
- whether external contributions are accepted immediately
- what level of support is promised
- whether language/platform branches are published together or incrementally

## Documentation Notes

When the project is made public, the README should be updated to:

- describe the framework as a reusable open-source agent library
- explain trunk vs language/platform branches
- explain how downstream projects adopt the framework
