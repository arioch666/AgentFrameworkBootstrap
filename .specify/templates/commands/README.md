# Spec Kit commands (portable)

Command definitions in this folder are **provider-agnostic**. Any AI assistant should follow the markdown file literally when the user asks to run a command (e.g. `speckit-onboarding`).

| Command file | Purpose |
|--------------|---------|
| [onboarding.md](./onboarding.md) | First-time Spec Kit guided lab (disposable branch; do not merge lab artifacts) |

Other `speckit-*` commands may be supplied by your editor integration or copied from upstream Spec Kit; this repository's Cursor skills reference `templates/commands/*.md` where present.

**Invoke onboarding:** see [docs/speckit-onboarding.md](../../../docs/speckit-onboarding.md).
